# Plano de Estudo Angular 22 - Novidades

Este repositório contém o plano de estudo estruturado para as novas funcionalidades do Angular 22, organizado em duas semanas de conteúdo.

## [Semana 1] Fundações Zoneless, Signals e Componentização Moderna

### Dias 1 e 2 ──► Projeto 1: Todo List Dinâmica (Zoneless, @for + @empty)
- Explorar modo Zoneless
- Implementar `@for` loop with trackBy
- Utilizar `@empty` para estados vazios
- Criar uma lista de tarefas interativa

### Dias 3 e 4 ──► Projeto 2: Dashboard Financeiro (Signal Grafo, computed, effect & Debugging)
- Criar sinais interconectados
- Implementar `computed` properties
- Usar `effect` para side effects
- Técnicas de debugging com sinais

### Dias 5 e 6 ──► Projeto 3: Mini E-commerce (A Tríade: input, output, model & inject)
- Componente pai-filho com `@Input`
- Eventos `@Output`
- Injeção de dependências com `inject()`
- Aplicar os três conceitos principais

## [Semana 2] Formulários Estáveis, Arquitetura Funcional e Testes

### Dias 7 e 8 ──► Projeto 4: Cadastro Avançado (Signal Forms Estáveis)
- Signal Forms substitutivo aos forms tradicionais
- Validação baseada em sinais
- Controle de estado reativo

### Dias 9 e 10 ──► Projeto 5: Portal com Autenticação (Guards & Interceptors Funcionais)
- Guards funcionais com sinais
- Interceptors baseados em sinais
- Proteção de rotas avançada

### Dias 11 e 12──► Projeto 6: Portal de Notícias (Deferrable Views + Vitest Nativo)
- `@defer` para carregamento preguiçoso de componentes
- `@loading` e `@placeholder` states
- Vitest nativo para testes unitários
- Testes de integração com sinais

---

**Objetivo:** Dominar as novas funcionalidades do Angular 22, focando em arquitetura reativa com sinais, componentização moderna e patterns de testes atualizados.
